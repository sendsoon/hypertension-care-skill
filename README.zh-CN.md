# hypertension-care-skill

[English](README.md) | **简体中文**

给编程智能体用的高血压长期管理技能。面向成年人，尤其是中老年、合并多种疾病、长期服药、行动能力下降或用药情况复杂的人。

它帮助患者理解血压、把测量做成习惯、看懂已经在用的药、按自己的身体情况调整吃饭和活动，并在出现危险时提示就医。它**不**诊断、**不**开药、**不**擅自停药或改剂量，也**不**代替医生面诊、检查和处方。

技能正文和参考资料是英文，便于工作流稳定。和患者对话时使用患者正在使用的语言。患者档案用英文写。

本仓库还没有对外发布的安装名。`skills-lock.json` 只标明这是本地技能，没有虚构上游提交号。

## 技能做什么

患者说出一个真实情况后，智能体会：

1. 用患者选定的昵称对应**一位**已有档案；对不上就先问，不把两个人的资料混在一起
2. 阅读该患者的基础情况、疾病、用药、近期血压和上一次建议
3. 先看有没有急救信号，再谈日常问题
4. 分开指南推荐、临床常识、针对此人的建议，以及尚未核实的信息
5. 给出下一餐、下一次测量或下一次就诊可以执行的步骤
6. 缺关键信息时只问最要紧的一个问题
7. 在患者确认后更新档案，并追加日志，不覆盖、不删除既往重要记录

WHO、ISH、ESC、AHA/ACC、中国高血压防治指南和 KDIGO 的血压目标并不相同。技能会说明差异，不会替这个人合成一个新目标。

## 患者档案

档案在当前工作区的 `hypertension-care-records/<昵称>/`。目录名就是患者愿意被称呼的昵称，对话里也用这个昵称，不另编编号。

每条临床信息标明来源：患者自述、医生已确认、AI 评估，或未知/未核实。

除该目录下的说明文件外，档案和日志已写入 `.gitignore`，不应提交。仓库里没有真实病历。虚构格式见 [examples/record-template.md](examples/record-template.md)。

不要记录真实姓名、身份证号、家庭住址或电话。

## 何时使用

适用于高血压、家庭血压、已经开具的降压药、限盐和聚餐、步行和其他活动、睡眠、出行、工作和合并心、脑、肾或代谢疾病时的日常管理。

不要用它为儿童套用成人方案，不要用它放行高强度运动，不要在胸痛、呼吸困难、意识改变、突发肢体无力或言语障碍时继续常规问答。中国大陆医疗急救电话是 120，其他地区使用当地急救电话。

## 智能体如何加载

根目录 `SKILL.md` 是唯一完整入口。`.agents/` 和 `.claude/` 里只有指向根目录的短入口，避免把同一套医学资料复制两份。

换一个智能体使用时，请同时复制 `SKILL.md`、`references/` 和 `examples/`，并保持相对路径不变。

## 用法

```text
我 70 岁，今天服药前测了两次，168/92 和 164/90。每天吃半片，但说不清药名。今天该怎么办？
吃氨氯地平后晚上脚踝肿，周六聚餐前能不能先停掉？
一起身就晕，坐着测是 102/64。
```

药名或剂量不清楚时，智能体应请患者看药盒，而不是猜。

## 回答长什么样

有急救症状时，整段回答就是急救步骤。

简单问题不强制写满七段。

具体问题用中文时按这七段：

1. 问题判断
2. 原因分析
3. 风险评估
4. 具体建议
5. 日常注意事项
6. 就医及检查建议
7. 后续跟踪

虚构示例见 [examples/output-template.md](examples/output-template.md)。

## 项目结构

```text
hypertension-care-skill/
├── SKILL.md                          # 智能体入口
├── skills.sh.json                    # 若将来发布，用于 skills.sh 分组
├── skills-lock.json                  # 本地锁，无上游哈希
├── README.md
├── README.zh-CN.md
├── LICENSE
├── .agents/skills/hypertension-care-skill/SKILL.md
├── .claude/skills/hypertension-care-skill/SKILL.md
├── references/                       # 指南、药物、合并症、生活、老年、急救、随访
├── examples/                         # 回答示例与虚构档案
└── hypertension-care-records/        # 本地档案，除 README 外不提交
```

| 文件 | 作用 |
|---|---|
| `SKILL.md` | 智能体执行的流程、安全规则和档案规则。 |
| `references/` | 需要时才阅读的医学与管理资料。 |
| `examples/` | 回答结构和虚构档案，不是真实患者。 |
| `hypertension-care-records/` | 每位患者一个昵称目录。 |
| `.agents/`、`.claude/` | 让从这两个目录加载技能的智能体回到根目录 `SKILL.md`。 |
